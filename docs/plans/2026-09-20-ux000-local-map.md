# UX-000 local geographic baseline

Status: implementation and validation in draft PR #1729; bounded Standard UI
repair after issue #1725. Not yet accepted or merged.
Base:7230cef6942871fb9eea04ebed4dffdb258ca6b7.

## Goal and acceptance

Default dark/light main maps must display basic geographic context without a
provider key or external basemap dependency, retaining camera, intelligence
overlays, picking and country interaction. Explain that country outlines do
not provide streets or terrain. Preserve explicit saved satellite/terrain choices
and theme-following dark/light preferences. Native useful coverage remains open.

## Design and boundaries

Use bundled countries geometry already loaded by country-geometry.ts and
DeckGLMap.loadCountryBoundaries. Default style shells contain a themed ocean
background; existing geometry load adds visible land/borders before unchanged
interaction layers. No external tiles/glyphs/sprites/terrain for this baseline.
Make pending/unavailable local geography truthful in Home-visible status, with
correct initial and switched attribution. Preserve overlays if geography fails.

No geometry/identifier changes, provider swap, new key, dependency, endpoint,
protocol, credential/cache-verification change, prediction or native change.
Emergency captured-map behavior remains distinct. No blanket PWA offline claim:
current web precache does not include geojson; packaged asset and blocked-remote
browser testing are different evidence.

## Validation findings and refinements

The first browser matrix passed eight scenarios in each of full, tech and
finance. Visual inspection then found that the headerless harness inherited a
production header offset, clipping the bottom of its fixed-height map. Stronger
viewport assertions and a local-basemap-only harness sizing correction are
required before visual acceptance. Architecture review separately confirmed that
Classic's expanded layer menu covers the initial bottom-left status. Scoped
Classic/Home positioning and control-intersection checks address that actual UI
defect; increasing stacking order over controls is not the remedy.

The initial earthquake mouse-popup attempt failed because the existing public
DTO uses nested location coordinates while the unchanged earthquake renderer
reads top-level lon/lat. Independent review verified this at base7230cef.
The representative overlay test uses an existing NaturalEvent fixture with real
mouse picking and popup assertions, including missing geography. Earthquake
rendering remains an explicit follow-up defect; this PR does not verify every
overlay type.

The legacy tech visual comparison also fails on unchanged base7230cef at the
same conflicts-z4 snapshot. Preserve both failures and investigate the cause;
do not blindly regenerate snapshots or count this check as passed.

## Verified placement and browser evidence (2026-09-22)

The isolated candidate was rebased onto main 97faf76e0. Classic status now uses
scoped placement clear of the layer tray and time controls, with Home's original
lower-left placement restored during CSS adoption. At widths at or below 1200px,
only the ordinary legend reserves space above local attribution; SIGINT's
positioning and stacking order are unchanged.

The final matrix covers dark/light at 1280, 1200, 800 and 390px, including expanded
and collapsed controls, Home adoption and release, unclipped map/viewport bounds,
status/control intersections and attribution/legend intersections. Full browser
coverage passed 16 cases; final Tech and Finance placement each passed 8 cases,
with their earlier full 14-case browser suites also passing. Local-map tests
passed 15 cases and map compatibility passed 9. The named validation gate,
explicit Full build, unchanged bundle limits and Full/Tech golden loops passed.

Clean-tree applied-diff mutation proofs, actual red counts, restored checksums,
selective Tech fixture provenance and remaining verification limits are recorded
in [the validation report](../validation/PR-1729-LOCAL-BASEMAP.md).
The Tech conflict capture matched the accepted Full fixture byte-for-byte; the
missing Tech ADS-B fixture likewise matched its accepted Full fixture. Only
these two proven equivalents were changed, without tolerance changes.

UX-000 remains MONITOR. This browser slice does not close the packaged native
